# Funkot Player · 曲のライブラリ

クラブのフライヤーを手に取り、出演者の名前を追う感覚から設計した。濃い群青の版に桃色の楕円を回転させて重ね、紙色の余白に曲名を大きく刷る。模様はプレイヤーを識別する固定の印で、曲の音やジャケットを表さない。曲名を同じ左端に揃えるので、長い和文と欧文が混じっても次の曲を見失いにくい。

[単体の試作 HTML](index.html) をダウンロードしてブラウザで開く。外部通信、音源、ビルドは不要。曲・タグ・ファイル名は合成で、追加や編集はページを開いている間だけ有効。

## 曲を探して追加する

1. 「条件を編集」で「2015」「日本人」「アニメ」を順に入力し、制作年の「2015年」と任意タグの「日本人トラックメーカー」「アニソンremix」を選ぶ。「アニメ」には別表記の候補も残る。どのタグを採用するかは利用者が決める。
2. 「すべて一致 (AND)」のまま「1,233 曲を見る」を選ぶ。曲名・アーティストの検索語も併用できる。条件の帯から再編集し、「選択中」を開くと条件を個別に外せる。適用後も「直前に戻す」で復帰できる。
3. 「追加先」で再生待ちかプレイリストを選び、曲の右の＋で追加する。名前を押せば版名とファイル名まで確認できる。「複数選択」はチェックした曲をまとめて送る。通知には追加先、行にはその追加先への登録回数が出る。同じ曲を再度追加でき、お気に入りは曲ごとに一つ。再生元は上端に独立して表示する。
4. 一覧末尾の「試作の検証用シナリオ」から9条件、0件、待機、失敗と再試行、文字200%を再現できる。曲の詳細にはお気に入りとタグの編集がある。

## 設計上の判断

検索を候補の辞書・条件の下書き・確定した結果に分けた。分類と別表記検索から候補を絞り、同じ面で AND/OR を変えると確定前に件数を読める。閉じると下書きを破棄する。確定条件の帯は常に一行で、全条件は編集面に戻ると読める。候補と採用済み条件は別々に辿れる。制作年は単一値、ジャンルと任意タグは複数値。編集対象はプレイヤー内の曲データである。

曲を送る先は一覧に一度だけ表示し、各行には静かな＋を一つ置いた。通常倍率ではスクロール中も追加先が残る。詳細や検索は必要な時だけ紙面の上に開く。狭幅では下から開き、確定操作を下端に置く。

## 検証と画面

[操作検証](verify.cjs) は Chromium で 1280×900 のマウス操作と 412×915 のタッチ入力を実行する。24,640曲・3,214候補からの3条件検索、テキスト併用、条件解除・復帰、OR 切替、追加先切替、単曲・一括追加、9条件、0件、失敗からの再試行、文字200%での横あふれと確定操作、Enter・Escape のフォーカス復帰を確認した。Android 実機のソフトキーボードと支援技術での読み上げは未検証。
