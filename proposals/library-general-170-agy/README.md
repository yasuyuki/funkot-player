## 2. 統合デザインコンセプト：「Overprint Quiet」

Claude案のリソグラフ印刷Zineのような音楽文化の温度感（`--paper: #f2f3f7`、深い藍墨 `--ink: #1a1942`、蛍光ピンク `--pink: #ff3ea5`、青 `--blue: #1b56c4` の紙面粒子とテーマ継承）を保ちつつ、**主役を「検索条件スタンプ」から「曲名」へ反転**させました。

1. **一目で分かる初期画面と最上段からの曲名一覧**
   - Claude案で上部135px超を占めていた巨大タイトル・件数ブロックと2段スタンプを廃し、初期画面は「検索欄＋条件ボタン」の直下に `24,823 曲` の件数・`選択`・`並び順` と曲一覧が即座に始まります（Desktop `Y = 106px` / Narrow `Y = 107px`）。
2. **有界・1行・下線型の検索条件バー（`#condBar`）**
   - 検索条件が付いても大型ピンクピルを並べず、Cursor案の「インクの下線文」とOverprintの蛍光ピンクを統合した**1行固定の下線トークン**で表示します。
   - トークンは固定個数に縛らず実幅を計測し（`fitCondBar`）、Desktopで入り切る分（通常3〜4条件）を表示し、9条件や長大タグ名が重なった場合は `+他7条件 (全9)` ボタンへ畳むため、**3条件でも9条件でも一覧開始位置が `Y = 150px`（Desktop）/ `155–157px`（Narrow）で一定**です。
3. **静かな2行リストと1操作追加**
   - 既定行は **曲名（18px太字、版表記は細字で階調付け）** と **アーティスト（＋必要時のみ `同名2件 · MP3` / `ファイルなし` / `非Funkot` / `再生中`）** のみに抑え、毎行4個の常設タグ表示を廃止しました。OR検索・文字列検索時のみ控えめな `一致: <語>` を添えます。
   - 行末の追加ボタンは物理 **48×48px**（WCAGタッチ基準準拠）を保ったまま、視覚輪郭を **26px・薄枠線** に抑え、曲名との視覚面積比 **23.1倍**（Desktop）を実現しています。
4. **オンデマンド切替の追加先ドック＋狭幅の「再生元」明示**
   - Desktop右ドックは現在の追加先（色バー＋名前＋件数＋`再生元と同じ` バッジ）と `末尾の曲` のみを静かに表示し、5つの追加先ラジオ群は `切替 ▾` を押したときだけ開きます。
   - Narrow（`412×915`）ではClaude案で隠れていた **`再生元: 再生待ち`** を下部再生バーに常時復元し、直下の追加先バー（`48px`高）から1タップでシート切替できます。
5. **フル機能の段階的開示（Lens・詳細・タグ編集）**
   - `/` または `条件` ボタンで開く条件編集レンズは、Claude案の全能力（制作年棒グラフ、ローマ字/かな正規化、表記揺れ一括OR追加、各条件ごとの一時停止・`これ以外`・行内OR、最近の条件、リアルタイム件数予測）に加え、agy案由来の **4分類ファセットタブ（おすすめ／制作年／ジャンル／タグ分類）** を備えます。
   - 行のタップで開く詳細カードに、全曲名、ジャンル/タグ（クリックで条件追加）、インライン `タグを編集`、`手動でFunkotとして許可`、同名別ファイル個別追加、お気に入り・追加先切替を集約しました。

### 主操作の手順数・発見性
- **3条件AND検索 → 1操作追加**: `/`（または検索欄クリック）→ 語句入力・候補選択×3 → 曲一覧の行末 `+` 1クリックで即追加（Undoトースト＋ドック末尾ハイライト表示）。条件の確定に必須の適用ボタン待ちがなく、絞り込みと同時に曲名を確認可能。
- **追加先の切替**: Desktopは右上 `切替 ▾` → 宛先選択（2クリック）、Narrowは下端 `追加先` バー → 宛先選択（2タップ）。常時は現在名のみを明示し誤追加を防止。

## 4. 検証と視覚レビューで発見・修正した点

`node verify.mjs`（Playwright Chromium実操作・幾何・タッチ・200%拡大・`@axe-core/playwright` 10状態監査）および `node capture-and-compare.mjs` による全キャプチャ目視確認を実施しました。

- **自動操作・アクセシビリティ検証（`verify.mjs`）**: **36/36 項目通過**、JSエラー `0件`、axe-core `critical` / `serious` 違反 **`0件`**（Desktop 6状態・Narrow 4状態）。
- **目視レビューから修正した実不具合**:
  1. **条件トークンの縮小崩れ修正**: `.ctok` が `flex-shrink: 1` になっていたため9条件・狭幅時にトークン文字列が `"2..."` や `"日"` へ潰れる問題を視覚審査で発見。`flex: 0 0 auto` へ変更し、`fitCondBar` で入り切るトークンのみ表示して残りを `+他N条件` へ逃がすことで全表示トークンの可読幅（最小 `121px` 以上）を保証。
  2. **制作年ヒストグラムと未設定件数注記の重なり修正**: `desktop-a-browse` / `desktop-eight-edit` において `.years` 高（`68px`）に対して棒＋年ラベルがはみ出し下の注記と接触していた問題を、`.years` 高 `76px`・棒最大 `50px` へ調整して解消。
  3. **200%文字拡大リフローの対応**: `rem` 単位のフォント設計と `is-large-text`（`>=24px` 検出時単一列＋ボトムドックピル化）により、`640×450` ブラウザズーム200%と `1280×900` ルート文字200%拡大の両方で横溢れ `0px` を達成。
  4. **ARIA構造修正**: 候補内表記揺れバーを `role="listbox"` の外へ分離し、追加先ラジオ群の `<ul role="radiogroup"><li>` 構造を `<div role="radiogroup">` に改め、オフスクリーンドックの非表示化と `.tail` のキーボード到達性を確保。
