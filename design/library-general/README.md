# Sleeve

Funkot Player の一般向けライブラリの操作試作。[Sleeve.zip](Sleeve.zip) を展開し、中の `Sleeve.html` をブラウザで開く。ネットワーク接続やインストールは不要。曲とタグは合成データを使い、操作結果は開いている間だけ保持する。

曲名、アーティスト、年、タグを検索欄に入力すると、候補を選んだ後の曲数が分かる。「結果を見る」で一覧に戻り、行末の ＋ で表示中の追加先に入る。同名曲は形式と長さで区別でき、曲名から詳細とタグ編集を開ける。
